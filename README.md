# toffCo_backend

Sistema backend para gerenciamento de vendas de filamentos e produtos variados de impressão 3D.

## Escopo inicial

- Cadastro e controle de produtos (filamentos e itens de impressão 3D)
- Controle de estoque por produto
- Registro de vendas com itens, quantidade e valor
- Cadastro básico de clientes
- Acompanhamento de faturamento por período
